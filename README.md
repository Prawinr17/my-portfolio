# Praveen R — Portfolio

> Personal developer portfolio built with a Naruto theme. Live at [praveen-r-portfolio.vercel.app](https://praveen-r-portfolio.vercel.app)

## Tech Stack

- **React.js** + Vite
- **Tailwind CSS v4**
- **Framer Motion** — animations
- **Web3Forms** — contact form
- **Vercel** — deployment

## Features

- Naruto-themed UI with custom animations
- Interactive chatbot (personal ninja assistant)
- Fully working contact form (Web3Forms)
- Resume download
- Scroll progress bar + back to top
- Custom kunai cursor
- SEO + GEO optimized (JSON-LD, Open Graph, llms.txt)
- Google Search Console indexed

## Sections

Hero → About → Skills → Experience → Projects → Education → Certificates → Contact

## Run Locally

```bash
npm install
npm run dev
```
